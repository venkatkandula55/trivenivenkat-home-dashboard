# TriveniVenkat's Home Dashboard

A centralized smart home dashboard displaying appliances, electricity, water, CCTV & security, Roborock, and thermostats in one place.

Live at: https://venkatkandula55.github.io/triveni-home-dashboard/

## Sections
- Home Overview (energy, temperature, water, security summary)
- Home Appliances (9 connected devices with toggle controls)
- Electricity (usage, bills, 30-day and hourly charts)
- Water (usage, bills, 30-day and weekly charts)
- CCTV & Security (Eufy cameras, system status)
- Roborock (S8 Pro status, schedule, history, start cleaning)
- Thermostats (4 thermostats with +/- controls)

Built with vanilla HTML/CSS/JS, Chart.js, Font Awesome.
